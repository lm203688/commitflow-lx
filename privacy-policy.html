CommitFlow Privacy Policy

Last updated: 2026-11-20

1. What we collect

CommitFlow does not collect any personal data or usage telemetry. All operations happen locally on your machine.

The only network call occurs when you activate a Pro license key against our verification endpoint (snapmark-license.61960005.workers.dev). This transmits only the license key string (a short alphanumeric token); our Cloudflare Worker backend validates it against KV storage and returns a boolean. No other data is sent.

2. What data we store

All local data is stored in VS Code's globalState:

  • Split rules — name, type (directory/ext/regex), pattern value, default commit message.
  • Commit templates — title and message text.
  • Pro flag + license key — stored locally; the key is also submitted to the verification endpoint during activation.

We do not create any files outside VS Code's standard data directories, and we never upload commit history, diffs, or working-tree content anywhere.

3. Third-party services

  • Paddle Billing — processes payment for the Pro upgrade. See the Paddle Privacy Policy.
  • Cloudflare Workers + KV — hosts the license verification API at snapmark-license.61960005.workers.dev. Cloudflare's standard logging applies to this endpoint. License keys are stored in Cloudflare KV (marked expired on cancellation, not deleted).

There is no third-party analytics, advertising, or tracking within CommitFlow.

4. Data retention

Since no user data leaves your machine, there is nothing for us to retain. The license verification log may contain the timestamp of your last request; this is not linked to your identity and is used solely for operational monitoring.

5. Contact

For privacy-related questions, email privacy@lxstudio.dev.

6. Changes

We may update this policy. Continued use after changes constitutes acceptance of the new terms.
